# Reconnaissance

## Overview

Reconnaissance is the first phase of the attack lifecycle where an adversary gathers information about the target environment before attempting exploitation. During this phase, the attacker used Gobuster from a Kali Linux attack machine to enumerate publicly accessible web resources hosted on the NAD Cybersecurity Institute student portal (**example.com**).

The objective was to identify hidden directories, discover accessible resources, and map the exposed attack surface. The reconnaissance activity generated telemetry that was successfully detected and investigated using Wazuh.

---

# Objectives

- Perform web content discovery against the target application.
- Identify hidden directories and web resources.
- Generate reconnaissance telemetry for detection.
- Validate Wazuh's ability to detect web scanning activity.

---

# Attack Scenario

Following the phishing campaign, the attacker initiated reconnaissance against the exposed web application to identify directories and resources that could be leveraged during later stages of the attack.

Gobuster was used to enumerate directories on the target web server. Multiple HTTP requests generated by the scan were detected by Wazuh, allowing the SOC analyst to investigate the activity and correlate the alerts.

# Findings

The investigation confirmed active reconnaissance against the target web application.

Key observations included:

- Automated directory enumeration using Gobuster.
- Multiple HTTP requests generated within a short period.
- Numerous HTTP 400 responses indicating unsuccessful directory requests.
- Successful detection by Wazuh.
- Complete alert context available for analyst investigation.

No exploitation occurred during this phase.

# Lessons Learned

Web reconnaissance is often the first observable stage of an attack. Although directory enumeration is considered a low-noise activity, properly configured security monitoring platforms can detect scanning behavior before exploitation occurs.

Early detection of reconnaissance provides defenders with valuable opportunities to investigate suspicious activity and implement containment measures before attackers progress further in the attack lifecycle.
